# Публикация сайта

Адрес: https://asdffffaa.github.io/YaninaWeb/

GitHub Actions автоматически собирает и публикует сайт после каждого push в `master`.
Ход публикации виден во вкладке Actions репозитория, workflow `Deploy site to GitHub Pages`.
Повторную публикацию можно запустить вручную кнопкой Run workflow.

В Settings → Pages выбран источник GitHub Actions. Публикуется только готовая папка `dist`.
Сценарий `scripts/build-github-pages.mjs` задаёт адрес `/YaninaWeb/` и исправляет пути
к изображениям и шрифтам только в готовой сборке. Исходные компоненты, CSS и медиа не меняются.
Обычная локальная команда `npm run build` продолжает работать как раньше.

Для обновления из `C:\Work\Presentation` сначала выполните `git pull --ff-only`,
затем внесите свои изменения, сделайте commit и push. Дождитесь успешной публикации в Actions.

Это статический хостинг существующего сайта. Он не добавляет платёжный API,
автоматическую выдачу материалов или запуск Telegram-бота.
