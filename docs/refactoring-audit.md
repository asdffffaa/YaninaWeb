# Состояние после восстановления оригинального дизайна

10 октября 2026 пользователь отклонил визуальную переработку. Восстановлены исходные геометрия и масштабирование из Git-версии до аудита.

## Восстановлено

- Исходные ширины и высоты секций, отступы, размеры карточек и расположение изображений.
- Компьютерный холст 1920 px и мобильный 402 px с прежним масштабированием.
- Первоначальный хедер с семью ссылками и интервалом 48 px.
- Прежние количество карточек и шаги каруселей, раскрытие каталога и мобильные анимации.
- Удалён экспериментальный `src/responsive.css`. Стили и экспорт Figma совпадают с исходной версией.

## Сохранено без изменения макета

- Проверки восстановления корзины, защита от неизвестных и повторяющихся ID.
- Сохранение e-mail, согласий и способа оплаты при смене мобильного/компьютерного макета.
- Улучшения фокуса модального окна, Escape и восстановления прокрутки.
- Тесты, проверка TypeScript, форматирование и безопасная очистка Python-кода.

## Проверки и ограничения

Команды: `npm run build`, `npm test`, `npm run test:browser`, `npm run test:bot:static`, `npm run format:check`.

Браузерные проверки охватывают ширины 320–2560 px, исходные пропорции, карточки, каталог, корзину, формы оплаты и сохранение введённых данных. Проверки выполняются в Chromium, не на физических телефонах. Снимки исходного вида дополнительно просмотрены на компьютере и телефоне.

Адаптация с неизменным физическим размером шрифтов пока не завершена. Приоритет восстановления — сохранить оригинал; прежнее масштабирование также восстановлено, а не выдано за новую адаптивность.

Реальная онлайн-оплата и автоматическая выдача материалов изначально не подключены. Python-бот проверен офлайн, без запуска Telegram и без реальных платежей.
